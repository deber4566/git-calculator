# My Calculator

A simple calculator built using HTML, CSS and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage (converts display value into decimal percentage)
- Sign toggle (+/-)
- Square root (√)
- Square (x²)
- Power (^)
- Error handling (Division by zero, negative square roots)
- Calculation history panel (view, recall, and clear history)
- Clear the display

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open the index.html file in a web browser.
